# #109 — Remove a stuck "Connecting…" contact — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Let a user remove an unconnected (pending) contact from the UI and CLI, fully wiping its local state so a fresh invite/add starts clean; connected contacts keep today's soft-archive.

**Architecture:** `Command::RemoveContact` becomes state-aware in the daemon — it hard-purges every peer-keyed row in one transaction when the contact is pending (`is_pending`), and soft-deletes (today's behavior) when connected. A new `Event::ContactRemoved` and a new `CommandResult::ContactRemoved { hard }` let the CLI and UI report/react. The CLI gains a `remove` subcommand; the UI gains a Remove action with a confirm dialog.

**Tech Stack:** Rust (rusqlite 0.38, ts-rs), Tauri 2 + SvelteKit (vitest), clap.

**Spec:** `docs/superpowers/specs/2026-07-20-issue-109-remove-pending-contact-design.md`

```rust
async fn remove_contact<S>(
    handle: &Arc<DaemonHandle<S>>,
    contact: crate::identity::PublicKey,
) -> std::result::Result<CommandResult, IpcError>
where
    S: AsyncRead + AsyncWrite + Unpin + Send + 'static,
{
    use crate::daemon::error_kind::DaemonErrorKind;
    use crate::daemon::events::Event;
    use crate::storage::first_contact_acks::FirstContactAckRepo;
    use crate::storage::pending_welcomes::PendingWelcomeRepo;
    use crate::storage::{ContactRepo, MessageRepo, MlsGroupRepo, OutboxRepo};

    let contact_repo = ContactRepo::new(&handle.pool);
    if contact_repo.get(&contact).map_err(map_err)?.is_none() {
        return Err(IpcError::Daemon(DaemonErrorKind::ContactNotFound));
    }

    let pending = PendingWelcomeRepo::new(&handle.pool)
        .is_pending(&contact.0)
        .map_err(map_err)?;

    if pending {
        // Hard purge: wipe every peer-keyed row atomically so a fresh invite
        // starts clean (#109). group_id may be absent if add never linked one.
        let group_id = contact_repo.get_group_id(&contact).map_err(map_err)?;
        handle
            .pool
            .transaction(|tx| {
                if let Some(gid) = group_id.as_deref() {
                    MlsGroupRepo::new(&handle.pool).delete_in_tx(tx, gid)?;
                    MessageRepo::new(&handle.pool).delete_by_group_in_tx(tx, gid)?;
                }
                PendingWelcomeRepo::new(&handle.pool).delete_in_tx(tx, &contact.0)?;
                FirstContactAckRepo::new(&handle.pool).delete_by_peer_in_tx(tx, &contact.0)?;
                OutboxRepo::new(&handle.pool).delete_by_target_in_tx(tx, &contact.0[..])?;
                ContactRepo::new(&handle.pool).remove_in_tx(tx, &contact)?;
                Ok(())
            })
            .map_err(map_err)?;
    } else {
        // Connected contact: soft-archive (unchanged pre-#109 behavior).
        contact_repo.set_hidden(&contact, true).map_err(map_err)?;
        let _ = PendingWelcomeRepo::new(&handle.pool)
            .delete(&contact.0)
            .map_err(|e| tracing::warn!(error = %e, "remove_contact: pending_welcome cleanup failed"));
    }

    let _ = handle.events_tx.send(Event::ContactRemoved(contact));
    Ok(CommandResult::ContactRemoved { hard: pending })
}
```

```rust
async fn remove(contact_prefix: &str, sock_flag: Option<&str>, _json: bool) -> anyhow::Result<()> {
    use skattr_core::daemon::{Command as CoreCommand, CommandResult};

    let mut client = connect_or_exit(sock_flag).await?;

    let rows = match client.execute(CoreCommand::ListContacts).await {
        Ok(CommandResult::Contacts(rows)) => rows,
        Ok(other) => anyhow::bail!("unexpected result: {other:?}"),
        Err(e) => exit_on_ipc_error(e),
    };
    let pubkey = match resolve_contact(&rows, contact_prefix) {
        Ok(pk) => pk,
        Err(e) => {
            eprintln!("{e}");
            std::process::exit(6);
        }
    };

    let result = match client
        .execute(CoreCommand::RemoveContact { contact: pubkey })
        .await
    {
        Ok(r) => r,
        Err(e) => exit_on_ipc_error(e),
    };
    match result {
        CommandResult::ContactRemoved { hard: true } => {
            println!("removed {contact_prefix} (local state wiped)")
        }
        CommandResult::ContactRemoved { hard: false } => println!("archived {contact_prefix}"),
        other => anyhow::bail!("unexpected result: {other:?}"),
    }
    Ok(())
}
```

```ts
/** Remove a contact via the daemon. For a pending contact the daemon

 *  from the store, so we do not refetch here. */
export async function removeContact(contact: string): Promise<void> {
  const resp = await ipcClient.request({
```
